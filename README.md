# Python Projects by Ayush Malviya

Two beginner-friendly console projects built with core Python: functions, loops, conditionals, lists, and dictionaries.

---

## 1. AI Study Buddy - Rule-Based Chat Assistant

A console chatbot that answers study questions using keyword matching. It does not use any external AI model.

**Features**
- Keyword matching with a Python dictionary
- Time-based greeting (morning / afternoon / evening) using the `datetime` module
- Chat keeps running until the user types `bye`, `exit` or `quit`

**Run**
```
python ai_study_buddy.py
```

**Sample**
```
Good evening! I'm AI Study Buddy.
You: tell me about dsa
Study Buddy: Start with arrays, strings, linked lists, stacks, queues, then trees and graphs.
You: bye
Study Buddy: Goodbye! Keep learning.
```

**Try asking about:** python, oop, dsa, array, sorting, recursion, study, exam, html, css, motivate, help

## 2. Expense Tracker

A menu-driven console tool to record and summarize daily expenses.

**Features**
- Add an expense (date, category, description, amount)
- View all expenses in a table
- Calculate total spending with a per-category summary
- Input validation and clean exit

**Run**
```
python expense_tracker.py
```

**Sample menu**
```
=== Expense Tracker ===
1. Add expense
2. View all expenses
3. Calculate total spending
4. Exit
```
